# 12 — GitHub workflow

Remote: https://github.com/Colouful/PhoneAgent

- Default branch: main.
- Work on feature branches.
- Keep commits small and reversible.
- Open PRs with purpose, scope, upstream SHA, validation, safety/privacy impact and known limitations.
- Run Swift tests and schema checks locally and in CI.
- Record real-device tests separately; CI never substitutes for hardware validation.
- Never force-push, reset shared history, commit API keys, Local.xcconfig, certificates, device passwords, private screenshots or logs.
- Create GitHub Issues from backlog/issues.md after checking for duplicates.
