# M0 Hardware Baseline Template

Copy this file to docs/test-results/M0-baseline.md during real-device validation.

Record test date, board revision, iPhone model and iOS build, macOS/Xcode/XcodeGen, Arduino CLI, exact ESP32 Arduino Core and NimBLE versions, upstream commit SHA, firmware/app builds and model provider. Never record secrets.

For each M0-01…M0-11 check, mark PASS / FAIL / BLOCKED_HARDWARE and attach a reproducible evidence path. Hardware tests require real-device proof; host tests are not substitutes. Do not mark M0 complete while required checks remain blocked.
