# Upstream notice and license review checklist

PhoneAgent intends to build on https://github.com/onehumanbeing/esp32-iphone-agent.

Before redistributing source or firmware:
- Preserve upstream NOTICE and required attribution.
- Review root and every nested license at the pinned commit.
- Upstream README identifies AirPlay code ported from UxPlay under GPL-3.0.
- Keep source availability and notices aligned with obligations for any distributed binary.
- Track NimBLE-Arduino, Arduino-ESP32, TinyUSB, VideoToolbox and model SDK assets separately.
- A root MIT license does not override nested GPL components.

This is a checklist, not legal advice.
