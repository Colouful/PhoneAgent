# Contributing

1. Read AGENTS.md, PROMPT_FOR_OTHER_AI.zh-CN.md, README.md and relevant docs first.
2. Keep changes small. Do not rewrite upstream AirPlay, BLE video transport or USB HID without measured evidence.
3. Add tests for Action, schema and protocol changes.
4. Record exact toolchain and upstream commit versions.
5. Separate host/unit tests from simulator and real-hardware tests.
6. Never commit API keys, provisioning profiles, Local.xcconfig, device Wi-Fi credentials, screenshots or private user data.
7. Preserve third-party licenses and notices; read docs/11-license-review.md.
8. PRs must list purpose, changed files, tests, results, limitations and hardware status.
9. Never claim unrun tests or overwrite shared history.
